# 📍 Helegel - Diyarbakır Kültür ve Turizm Rehberi

**Helegel**, Diyarbakır'ın tarihi, kültürel ve turistik değerlerini keşfetmeyi kolaylaştıran modern bir şehir rehberi ve tanıtım uygulamasıdır. Kullanıcıların şehrin tarihi mekanlarını, lezzet noktalarını ve gezi rotalarını interaktif haritalar ve kategorize edilmiş içeriklerle kolayca keşfetmesini sağlar.

---

## 🌟 Öne Çıkan Özellikler

- 🗺️ **İnteraktif Şehir Haritası:** Leaflet ve OpenStreetMap entegrasyonu ile tarihi yapıları ve gezilecek yerleri harita üzerinde görüntüleme.
- 🏛️ **Kategorize Gezi Noktaları:** Tarihi mekanlar, gastronomik duraklar, müzeler ve kültürel rotalara hızlı erişim.
- 🗣️ **Yerel Sözlük & Söz Dizimi:** Diyarbakır ağzına ait özgün kelimeler, deyimler ve pratik diyalog kartları.
- 🚌 **Ulaşım Rehberi:** Şehir içi ulaşım hatları, otobüs güzergahları ve önemli lokasyonlara erişim bilgileri.
- 📱 **Duyarlı (Responsive) Tasarım:** Mobil, tablet ve masaüstü cihazlarla tam uyumlu kullanıcı arayüzü.

---

## 🛠️ Teknolojiler

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Harita Servisi:** Leaflet.js, OpenStreetMap
- **İkonlar & Tipografi:** Font Awesome / Google Fonts

## 🚀 Kurulum ve Çalıştırma

Proje bağımsız bir istemci tarafı (client-side) web uygulamasıdır. Herhangi bir backend veya paket yöneticisi kurulumu gerektirmez.

1. Repoyu klonlayın:
   ```bash
   git clone https://github.com/suaybsavcu/helegel-tourism-promotion-application.git
   ```
2. Proje dizinine gidin:
   ```bash
   cd helegel-tourism-promotion-application
   ```
3. `index.html` dosyasını doğrudan tarayıcınızda açın veya **VS Code Live Server** eklentisini kullanarak çalıştırın.
